# Transformers vs. web spam: M.Sc. thesis project page

Interactive project page for my M.Sc. thesis (Bauhaus-Universität Weimar, 2025): a hybrid DistilBERT pipeline and a TF-IDF + SVM detector for spam reviews and AI-generated text across 8 million search results (2022–2024).

Open `index.html` in a browser, or view the live page on GitHub Pages.
